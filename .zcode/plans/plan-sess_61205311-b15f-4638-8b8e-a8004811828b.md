# 上线就绪:5 件套(必须 + 强烈建议)

## 场景定位
SMU BIA 黑客松社团面试 portfolio,部署到 Vercel 拿到分享链接。重点:能打开、不翻车、显专业。

## 探查结论
- ❌ 无 Git 仓库,`.gitignore` 没排除 78MB 的 `avatar.original.glb`
- ❌ `index.html` title 是 "3d-resume",无 description/OG 标签
- ❌ 移动端:Skills/Projects 固定宽度面板会遮挡 3D 且挤压
- ❌ 加载只有 "Loading..." 文字,3.4MB 模型无进度
- ❌ 无 WebGL 降级,不支持设备白屏

---

## Step 1:Git 初始化 + 修 `.gitignore`(必须)

### 1.1 在 `.gitignore` 追加(排除大模型备份 + 构建产物)
```
# 大模型原始备份(压缩版 avatar.glb 才是生产用的)
public/models/avatar.original.glb

# 系统
.DS_Store
```
> 注:`dist`、`node_modules` 已在原 .gitignore 里。

### 1.2 初始化 git + 首次提交
```bash
git init
git add .
git commit -m "feat: 3D resume with R3F, Tailwind, section narrative"
```
> 因 `avatar.original.glb` 已被 ignore,78MB 不会进仓库,仓库会很轻量。

## Step 2:移动端适配(必须)

策略:`md:` 断点(768px)分流。PC 保持侧边浮层,移动端改为底部抽屉。

### 2.1 `SkillsSection.jsx`
- PC:`right-6 top-1/2 w-72`(现状)
- 移动:`bottom-6 left-6 right-6 w-auto`(底部横向铺满,3 列技能改 1 列纵向)
用 `hidden md:block` + `md:hidden` 两套布局,或用响应式 class 切换。

### 2.2 `ProjectsSection.jsx`
- PC:`left-6 top-1/2 max-w-md`(现状)
- 移动:`bottom-6 left-6 right-6 w-auto`(底部,占下半屏可滚动)

### 2.3 `TopNav.jsx`
- 移动端:Logo 缩小,导航项 padding 收紧,避免换行
- 用 `text-[10px] md:text-xs`、`px-2 md:px-4`

### 2.4 `AvatarCanvas.jsx`
- 移动端相机距离调远一点(模型小些给 UI 让位)
- 通过 `window.innerWidth` 判断,或用 drei 的 `useViewport` 

## Step 3:SEO 基础(必须)

改 `index.html`:
```html
<title>Eric Wang · Creative Frontend Engineer</title>
<meta name="description" content="Eric Wang 的 3D 数字简历 —— 沉浸式 Web 3D 个人主页">
<meta name="theme-color" content="#0a0a0a">

<!-- Open Graph(微信/Twitter/LinkedIn 分享卡片) -->
<meta property="og:title" content="Eric Wang · 3D Resume">
<meta property="og:description" content="沉浸式 Web 3D 个人主页">
<meta property="og:type" content="website">
<!-- OG 图:先用纯色占位,后续可换截图 -->
```
> OG 图暂用 favicon 或留空(微信会抓首屏),面试前你可截一张 3D 画面做 OG 图。

## Step 4:加载进度条(强烈建议)

改造 `AvatarCanvas.jsx` 的 `LoadingFallback`:
- 用 drei 的 `useProgress` 获取真实加载进度
- 显示百分比 + 进度条 + "Loading 3D Avatar..."
```jsx
import { useProgress, Html } from "@react-three/drei";
function LoadingFallback() {
  const { progress } = useProgress();
  return <Html center>...{Math.round(progress)}%...</Html>;
}
```

## Step 5:WebGL 降级 + 错误边界(强烈建议)

### 5.1 新建 `src/components/WebGLGuard.jsx`
- 用 `gl.getContext()` 或 try-catch 检测 WebGL 支持
- 不支持时显示降级 UI:"你的浏览器不支持 WebGL,请用现代浏览器访问" + 显示纯文字版简历(从 content.js 读)

### 5.2 App.jsx 包裹
```jsx
<WebGLGuard>
  <AvatarCanvas ... />
</WebGLGuard>
```
> 这样老设备/部分企业浏览器不会白屏,至少能看到文字简历。

## 验证
1. `git status` 确认 78MB 文件未暂存
2. `npm run build` 成功
3. 浏览器 DevTools 切移动端视图,UI 不遮挡
4. 分享链接卡片显示正确 title/description
5. 加载显示百分比

## 💡 这样做的目的
1. **Git + gitignore**:78MB 不进仓库 = 推送秒过、Vercel 部署快、面试官 clone 不卡。
2. **移动端**:面试官大概率手机点开链接,底部抽屉布局是手机原生体验,不会因遮挡 3D 显得粗糙。
3. **SEO/OG**:微信发链接给社长/面试官时,卡片显示你的名字+简介,而不是 "3d-resume" 空白卡,第一印象专业度拉满。
4. **进度条**:3.4MB 在手机弱网可能 2-3 秒,百分比进度让等待不焦虑,显工程素养。
5. **WebGL 降级**:兜底,任何设备都不白屏,这是"成熟作品"和"demo"的分水岭。

## 部署流程(代码就绪后,我给你步骤)
1. 推到 GitHub(`git remote add origin ... && git push`)
2. vercel.com → New Project → 导入 GitHub 仓库
3. Framework 选 Vite,自动识别 build 命令
4. 30 秒后拿到 `xxx.vercel.app` 链接,直接放简历/发面试官
