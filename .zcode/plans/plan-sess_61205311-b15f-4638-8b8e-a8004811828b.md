# 视觉优化:氛围背景 + 人物主导 + 胶囊 UI + 放大标题

## 核心问题诊断(来自代码探查)
1. **Canvas 有不透明 `#0a0a0a` 背景** → 任何 CSS 氛围层会被遮住,必须先让 Canvas 透明
2. **模型无 scale + FOV 35(偏窄)** → 模型显小,画面空旷
3. **5 个章节卡片定位各异**(左下/右中/左中/居中/全屏)→ 窗口变化时视觉重心乱跳
4. **纯黑背景无层次** → 缺乏景深和氛围

## 已确认决策
- 背景:光晕 + 网格 + 噪点(保留黑+紫+白)
- 布局:人物主导 + 胶囊 UI
- 字体:放大标题

---

## Step 1:背景氛围层(光晕 + 网格 + 噪点)

### 1.1 让 Canvas 透明
修改 `AvatarCanvas.jsx`:
- 删除 `<color attach="background" args={["#0a0a0a"]} />`
- Canvas 加 `gl={{ alpha: true }}`
- Environment 内的 `<color attach="background">` 也删除

### 1.2 在 App.jsx 加 CSS 氛围层(Canvas 之下)
新增一个绝对定位的背景层,包含:
- **径向紫色光晕**:CSS `radial-gradient`,中心 `rgba(192,132,252,0.15)` → 边缘透明,模拟模型后方的发光球
- **细网格**:CSS `linear-gradient` 重复,`rgba(255,255,255,0.03)` 极淡网格线,给空间感
- **噪点纹理**:SVG turbulence filter 生成的 base64 噪点,`opacity: 0.04`,增加质感不显塑料

### 1.3 index.css 加关键帧
- `glow-pulse`:光晕缓慢呼吸(8s 循环,opacity 0.6↔1)
- `grid-drift`:网格极慢平移(60s 循环),制造"数字空间"流动感

## Step 2:放大 3D 模型(人物主导)

修改 `AvatarCanvas.jsx`:
- **方法 A(主)**:给 `<group>` 加 `scale={1.5}`,模型放大 50%
- **方法 B(辅)**:FOV 35 → 30(略窄,模型在画面占比更大)
- **相机预设调整**:各章节 z 值统一略减(更近),但保留章节间的角度差异用于叙事
  - about: `[0, 1.5, 3.5]`(原 4)
  - skills: `[2.8, 1.5, 2.8]`(原 3, 3.2)
  - reel: `[4, 1.8, 3]`(原 4.5, 3.5)
  - projects: `[-2.8, 1.8, 2.8]`(原 -3, 3.2)
  - contact: `[0, 1.2, 2.4]`(原 2.8)
- 移动端同步调整保持比例

## Step 3:胶囊化 UI(统一布局,解决窗口适配)

### 3.1 统一定位策略
**所有章节卡片改为"底部居中胶囊"**(除 Reel 特殊处理):
- 桌面:底部居中,`max-w-2xl`,`rounded-3xl`(更圆润的胶囊)
- 移动:底部铺满,`left-4 right-4 bottom-4`
- 这样无论窗口怎么变,卡片始终在底部居中,视觉重心稳定

### 3.2 卡片瘦身
- padding:`p-5 md:p-6` → `p-4 md:p-5`(更紧凑)
- 内容精简:About 段落限制 2 段(其余折叠或省略),Skills 改横向滚动条,Projects 限制显示数量
- 圆角加大:`rounded-2xl` → `rounded-3xl`(胶囊感)

### 3.3 Reel 特殊处理
Reel 保持全屏,但视频容器改成圆角胶囊 `rounded-3xl`,文字部分缩小,让视频本身成为主体。

### 3.4 TopNav 微调
- 胶囊已经够紧凑,保持现状,只把 padding 再收紧一点避免和放大后的模型冲突

## Step 4:放大标题字体

### 4.1 About 姓名
- `text-2xl md:text-3xl` → `text-4xl md:text-5xl font-bold tracking-tight`
- 让姓名成为视觉焦点之一,填补上方空白

### 4.2 章节小标题
- `text-xs tracking-[0.2em]` → `text-sm tracking-[0.3em]`(略大)

### 4.3 tailwind.config.js(可选)
加 `fontFamily.display`:一个更醒目的字体栈(系统字体加粗),用于标题。不引入外部字体保持加载速度。

## 验证

2. 浏览器打开:背景有紫色光晕呼吸 + 极淡网格 + 噪点质感
3. 3D 模型明显变大,占据画面主体
4. UI 卡片统一在底部居中,窗口缩放不再"乱跳"
5. 姓名标题放大,成为视觉焦点

## 💡 这样做的目的
- **背景氛围**:纯黑太死,光晕+网格+噪点制造"数字空间"感,模型像悬浮在能量场中,高级感拉满,且保留黑紫白主调
- **人物主导**:放大模型 + 透明背景,让 3D 真正成为主角,填补画面空旷
- **统一胶囊布局**:解决"窗口变化布局乱跳"的核心痛点 —— 所有章节卡片都在底部居中,视觉重心永远稳定
- **放大标题**:姓名成为第二视觉焦点,和放大的模型形成上下呼应,填补垂直空白

## ⚠️ 取舍提示
背景的噪点纹理用 SVG 生成 base64,体积很小但会增加一点 CSS 复杂度。如果你觉得太花哨,我可以只保留光晕+网格,去掉噪点。但建议先全做,看了效果再决定减哪个。
